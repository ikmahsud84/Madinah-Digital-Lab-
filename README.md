# Madinah Digital Lab

A lightweight, responsive static website prepared for deployment through GitHub Pages.

## Files
- index.html — Home
- guides.html — Guides
- tools.html — Tools
- blog.html — Blog
- about.html — About
- contact.html — Contact
- privacy.html — Privacy Policy
- terms.html — Terms & Conditions
- disclosure.html — Affiliate Disclosure
- style.css — Site styling

## Before publishing
Replace the placeholder public contact email in `contact.html` with the email address you want visitors to use.

## Important
This website is designed as a strong foundation. Before applying to an affiliate network, add several genuinely useful original articles and real tool reviews/comparisons. Do not publish fabricated testimonials, traffic numbers, author credentials, or claims of personal experience you do not have.
